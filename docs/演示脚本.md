# 大白 · 省赛现场演示脚本

> 全程约 **5 分钟**。每一步都有"说什么 / 看到什么 / 卡住怎么办"。
> 所有回复都走**预存语音**，秒出；只有临时提问才走大模型。

## 一、开场（30 秒）

**你说：**
> "这是大白，一台面向独居老人的健康陪护机器人。它听得懂自然语言、记得住健康数据，摔倒时会先问一句再通知家属。"

**然后说：**
> **"你好大白"**

**屏幕会显示：**
```
▌唤醒命中

大白: 我在呢，您说。   [唤醒应答]

[系统] 免责声明：大白是健康陪护辅助工具，不能代替医生诊断，也不能代替拨打 120。

大白: 我可以帮您了解健康知识，但不能代替医生诊断。   [免责声明]
```

**评委看点**：唤醒到出声 **14 毫秒**，且主动声明"我不是医生"。

## 二、三类问答（60 秒）—— 核心创新点

**连续问三个问题，每个等它说完再问下一个。**

| 你说 | 它会答 |
|---|---|
| **"什么是高血压"** | 高血压是指动脉血压持续高于一百四十比九十毫米汞柱…（**定义**） |
| **"为什么会有高血压"** | 高血压和遗传、吃盐多、体重超标、长期饮酒…（**原因**） |
| **"有了高血压应该怎么办"** | 遵循医生制定的治疗方案，按医嘱服药…（**处置**） |

**屏幕会显示：**
```
▌聆听中…
   ● 录音 4.3s

我: 什么是高血压

大白: 高血压是指动脉血压持续高于一百四十比九十毫米汞柱。多数人没有明显感觉，
      所以被叫作无声的杀手，要靠测量才能发现。   [知识库·全文缓存]
      ⏱  总计 1.23s │ 录音 0.85s │ 语音识别 0.38s │ 知识检索 0.01s
```

**你这句要讲：**
> "同一主题下，'是什么、为什么、怎么办'会被分到不同的知识条目，答案完全不同——这是我们的三级意图识别。"

## 三、健康数据 + 卫健委分级（40 秒）

**你说：**
> **"我血压一百五九十"**

**屏幕会显示：**

```
大白: 这次血压偏高，安静休息十分钟再复测一次，还是高就联系医生。   [健康数据]
```

**你这句要讲：**
> "它把口语里的中文数字也识别了，按《中国高血压防治指南》自动分级：正常、正常高值、1/2/3 级，并且写进健康档案。"

**加分句**：可以再说一句 **"我血压一百八十比一百一"**，它会答 **3级高血压 / 危险**。

## 九、卡住了怎么办（背下来）

| 现象 | 立刻这样做 | 嘴里说什么 |
|---|---|---|
| 说"你好大白"没反应 | 靠近麦克风再说一次，说慢一点 | "稍等，它在听" |
| 回答到一半卡住 | 按 `s` 停止播报，重新问 | "我打断一下" |
| 跌倒没触发 | 直接按板子上的 `f` 键 | "我用键盘模拟一次跌倒" |
| 电话没打出去 | 不用慌，短信和钉钉已经发了 | "短信已送达，这是双通道" |
| 面板打不开 | 跳过面板，口头报数据 | "面板数据我口头报一下" |
| 它开始胡说（走了大模型） | 立刻换成缓存问题再问 | "我换个问法" |

## 十、评委可能问的问题（准备好答案）

**Q：会不会误报？**
> 会先问一句，老人说"我没事"就撤销。而且判定要同时满足"自由落体→撞击→静止 1.2 秒"三个条件。

**Q：断网了怎么办？**
> 语音和知识库全在本地，断网照常对话；告警走 4G 短信，不依赖 WiFi。

**Q：这个能代替医生吗？**
> 不能。我们在启动、每次唤醒、面板页脚、告警短信四个地方都写了免责声明。它做的是"提醒、记录、及时通知"。

**Q：摄像头真的在判断吗？**
> 跌倒时抓拍并做人脸检测：画面里有人 → 常规通知；**看不到人 → 判断更危险，直接拨号**。

**Q：为什么响应这么快？**
> 常用回答和医疗知识都预生成成语音，命中缓存是**几十毫秒**级；只有临时提问才走本地大模型。

## 十一、绝对不要做

- ❌ 不要问知识库以外的问题（比如"今天天气"）——会走大模型，慢且可能胡说
- ❌ 不要说"人脸识别"——是**抓拍 + 人脸计数**，不是身份识别
- ❌ 不要演示 DHT11（硬件没接）
- ❌ 不要说"喇叭 3W"——现在是 USB 耳机出声
